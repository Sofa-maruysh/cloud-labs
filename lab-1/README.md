# Лабораторная работа 1 — nginx

nginx служит единой точкой входа для приложения из лабораторной работы 0. Он перенаправляет HTTP на HTTPS, самостоятельно отдаёт фронтенд, проксирует `/api` на два экземпляра Flask-бэкенда и продолжает обслуживать запросы после остановки одного экземпляра.

## Реализованные требования

- HTTPS с локальным самоподписанным сертификатом;
- перенаправление с порта 80 на 443;
- статика фронтенда через nginx и API через reverse proxy;
- round-robin балансировка между `backend-1` и `backend-2`;
- отдельный каталог `/docs/` через `alias`;
- виртуальные хосты `lab1.local` и `other.local`;
- ограничение запросов к `/api` со статусом 429;
- собственные страницы 404 и 50x;
- Basic Auth для `/admin/`;
- автоматическая проверка работы после остановки одного бэкенда.

Задание со звёздочкой в эту работу не входит.

## Запуск

Нужны Docker Desktop с Linux-контейнерами и Docker Compose v2.

```powershell
cd lab-1
docker compose up -d --build --wait
docker compose ps
```

Откройте <https://localhost>. Браузер предупредит о самоподписанном сертификате — для локальной лабораторной это ожидаемо.

Данные для `/admin/`:

- пользователь: `admin`;
- пароль: `lab1admin`.

Для второго виртуального хоста проверка использует заголовок `Host` автоматически. При желании открыть его в браузере добавьте в файл `hosts` строку `127.0.0.1 other.local`, затем откройте <https://other.local>.

## Проверки и материалы отчёта

В PowerShell из корня лабораторной:

```powershell
.\scripts\collect-evidence.ps1
```

Или в Git Bash:

```bash
bash scripts/collect-evidence.sh
```

Скрипт проверяет все пункты задания, временно останавливает `backend-2`, убеждается, что API продолжает отвечать, возвращает контейнер и сохраняет результаты в `evidence/`.

Успешный итог:

```text
Итог: OK=16 FAIL=0
```

Инструкция по трём скриншотам находится в `screenshots/README.md`.

## Остановка

```powershell
docker compose down
```

Том PostgreSQL остаётся, поэтому сохранённые задачи не пропадут. Полное удаление стенда вместе с данными:

```powershell
docker compose down -v
```
