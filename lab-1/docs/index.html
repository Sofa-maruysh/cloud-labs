Docs (alias)

Эта папка физически лежит отдельно от фронтенда и подключена в nginx через директиву alias:

location /docs/ {
    alias /usr/share/nginx/docs/;
    index index.html;
    autoindex on;
}

Содержимое папки:

  • nginx-quick-notes.md — конспект по директивам из лабы
  • checklist.md — чек-лист из задания
