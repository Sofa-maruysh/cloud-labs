# Лабораторная работа 0 — свой сервис

## Что это

Небольшое веб-приложение «Список задач». Фронтенд отправляет новую задачу в Flask-бэкенд. Бэкенд записывает задачу в PostgreSQL и читает сохранённые задачи для отображения на странице.

## Состав проекта

- `app/` — Flask-бэкенд и веб-страница;
- `db` — отдельный контейнер PostgreSQL, описанный в `docker-compose.yml`;
- `report.md` — отчёт по лабораторной работе.

## Запуск

1. Установить и запустить Docker Desktop.
2. В терминале перейти в папку лабораторной:

   ```bash
   cd lab-0
   ```

3. Запустить приложение и базу данных:

   ```bash
   docker compose up --build
   ```

4. Открыть в браузере <http://localhost:5000>.
5. Ввести задачу, нажать «Добавить» и обновить страницу. Задача останется в списке, так как она сохранена в PostgreSQL.

## Остановка

В окне терминала нажать `Ctrl + C`, затем выполнить:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в Docker volume `postgres_data`. Чтобы удалить и контейнеры, и данные, выполнить:

```bash
docker compose down -v
```
