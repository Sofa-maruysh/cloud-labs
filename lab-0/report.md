# Отчёт по лабораторной работе 0

## Репозиторий

Код лабораторной работы находится в публичном репозитории: <https://github.com/Sofa-maruysh/cloud-labs>.

## Цель работы

Собрать небольшой веб-сервис, в котором фронтенд передаёт данные бэкенду, а бэкенд сохраняет и читает их из отдельной базы данных PostgreSQL.

## Что я сделала

Я сделала сервис «Список задач». На странице есть поле ввода и кнопка «Добавить». После отправки формы Flask получает текст задачи и записывает его в PostgreSQL. Затем Flask читает все сохранённые задачи и показывает их на странице.

База данных не встроена в приложение: PostgreSQL запускается отдельным сервисом `db`. Это важно, потому что в следующих лабораторных базу можно будет контейнеризовать и настраивать отдельно от приложения.

## Как запустила

1. Установила Docker Desktop.
2. Открыла терминал в папке `lab-0`.
3. Выполнила команду `docker compose up --build`.
4. Открыла адрес <http://localhost:5050>.
5. Добавила задачу через форму и обновила страницу. Задача осталась в списке, значит она сохранилась в PostgreSQL.

Подробная инструкция запуска находится в [README.md](README.md).

## Результат

У меня получился небольшой сервис с фронтендом, бэкендом и отдельной PostgreSQL. Главный момент этой лабораторной — после обновления страницы добавленная задача не исчезает, потому что она хранится в базе данных, а не просто в памяти программы.
